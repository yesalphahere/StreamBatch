# StreamBatch - Product Roadmap & Development Status

This roadmap clarifies the boundary between implemented, tested features and planned future capabilities.

---

## 1. Completed & Verified Features (v1.0.0)

- [x] **PySide6 Qt Dashboard**: Clean slate dark UI (`DARK_THEME_QSS`) with responsive tables and custom delegate progress bars.
- [x] **Shallow Playlist Inspection**: Instant introspection of playlist tracks without downloading media streams (`extract_flat: "in_playlist"`).
- [x] **Selective Batch Job Creator**: Multi-track checklist table with Select All / Deselect All toggles.
- [x] **Audio Transcoding Pipeline**: Direct conversion to MP3, M4A, FLAC (Lossless), WAV (Lossless), AAC, and Opus via FFmpeg.
- [x] **Configurable Audio Quality**: Bitrate profiles for 320 kbps, 256 kbps, 192 kbps, 128 kbps, and Source/VBR 0.
- [x] **Video Stream Merging**: Merges highest quality video and audio streams into standard MP4 containers (1080p, 720p, Best).
- [x] **Non-Blocking Queue Management**: `QThreadPool` worker slots (1 to 10 concurrent threads) with pause, resume, cancel, and retry capabilities.
- [x] **10 Hz Signal Throttling**: Limits GUI progress updates to 100 ms intervals to ensure a smooth 60 FPS interface.
- [x] **SQLite WAL Persistence**: Database tracking of queue state and historical records with instant duplicate URL detection.
- [x] **FFmpeg Auto-Locator**: Intelligent discovery of FFmpeg binaries across WinGet, Scoop, Chocolatey, and system PATH.
- [x] **Manifest V3 Browser Extension**: Context menu and popup action dispatching URLs to StreamBatch over local loopback IPC.
- [x] **Windows Standalone Packaging**: PyInstaller specification and batch compilation scripts.

---

## 2. Planned Enhancements (Phase 2 & Beyond)

### A. Queue & Bandwidth Management
- [ ] **Global Bandwidth Throttler**: Slider in Settings to limit aggregate download speed (e.g. cap at 5 MB/s to preserve gaming/streaming bandwidth).
- [ ] **Overnight Scheduling**: Automated queue scheduler to run heavy playlist batches during off-peak hours (e.g. 02:00 AM – 06:00 AM).
- [ ] **Auto-Shutdown on Completion**: Optional toggle to put the computer to sleep or shut down once all queued items complete.

### B. Media & Metadata Capabilities
- [ ] **Subtitle Extraction**: Download and embed multi-language `.srt` / `.vtt` subtitles directly into video containers.
- [ ] **Cover Art Embedding**: Fetch high-resolution thumbnail images and embed them directly into MP3/M4A/FLAC ID3 tags via FFmpeg.
- [ ] **Multi-Segment Chapter Splitting**: Automatically split long single-file audio recordings into separate tracks based on chapter markers.

### C. Security & Browser Hardening
- [ ] **CORS Authentication Token**: Require a one-time cryptographic token generated by the desktop app and shared with the browser extension to prevent local origin spoofing.
- [ ] **Proxy Configuration**: SOCKS5 / HTTP proxy settings for users routing through secure tunnels or privacy proxies.
